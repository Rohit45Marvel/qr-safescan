QR-SafeScan

Cross-Platform Mobile QR Code Phishing Detection System

A privacy-preserving mobile security application developed at EPITA to protect users from malicious QR codes using real-time threat intelligence and advanced URL analysis techniques.

Key Features

⚡

Real-Time Threat Intelligence

Instantly analyzes QR code URLs against live threat databases and security feeds to identify malicious content before you access it.

🔒

Zero-Trace Privacy

Complete privacy protection with no user accounts, no tracking, and no scan history storage. Your data stays yours.

🚦

Smart "Traffic Light" Verdicts

Easy-to-understand color-coded results help you make instant decisions about URL safety.

🎭

Advanced Deception Detection

Sophisticated algorithms detect typosquatting, homograph attacks, and other domain spoofing techniques used in phishing.

📱

Cross-Platform Protection

Seamless security across iOS and Android devices, ensuring protection wherever you scan QR codes.
